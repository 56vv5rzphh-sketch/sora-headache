# そらと頭痛

気圧と体調を記録する、個人利用向けのインストール可能なWebアプリです。

## Privacy

Headache entries and weather snapshots are saved only in the browser's local storage on each device. This site does not upload personal log entries to GitHub or any server.

## Deployment

GitHub Pages publishes the static files directly from the root of the `main` branch.
